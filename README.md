## Project Overview

This project implements a complete Machine Learning Operations (MLOps) pipeline using MLflow, applied to the problem of predicting whether it will rain tomorrow in Australia based on today's weather observations.

The system covers every stage of the ML lifecycle:

| # | Objective | Implemented In |
|---|-----------|----------------|
| 1 | Experiment Tracking | `train.py` |
| 2 | Model Training and Hyperparameter Tuning | `train.py`, `tune.py` |
| 3 | Model Deployment (REST API) | `mlflow models serve` + `predict_client.py` |
| 4 | Performance Monitoring | `monitor.py` |
| 5 | Model Registry and Versioning | `register.py` |

---

## Dataset

**Rain in Australia** dataset (`weatherAUS.csv`) from Kaggle:
https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package

- ~145,000 daily weather observations from 49 Australian weather stations
- 23 features (temperature, humidity, wind, pressure, etc.)
- Binary target: `RainTomorrow` (Yes/No)

## How To Run

### 1. Setup

```powershell
# Create virtual environment
python -m venv venv

# Activate (Windows PowerShell)
.\venv\Scripts\Activate.ps1

# Install dependencies
pip install -r requirements.txt
```

### 2. Run The Pipeline (in order)

```powershell
# Step 1: Prepare the data (creates train.csv and test.csv)
python data_prep.py

# Step 2: Train 3 baseline models
python train.py

# Step 3: Run hyperparameter tuning (15 Hyperopt trials)
python tune.py

# Step 4: Register the final model in MLflow Registry
python register.py

# Step 6: Run drift monitoring (creates drift_monitoring.png)
python monitor.py
```

### 3. View Results in MLflow UI

In a separate terminal:

```powershell
mlflow ui
```

Then open: http://127.0.0.1:5000

### 4. Deploy The Model As a REST API

```powershell
mlflow models serve -m "models:/rain-classifier@production" -p 5001 --no-conda
```

In a second terminal, test it:

```powershell
python predict_client.py
```

## Results Summary

| Stage | Outcome |
|-------|---------|
| Baseline (Random Forest) | Accuracy: 0.851 / F1: 0.596 / ROC-AUC: 0.877 |
| Hyperopt Tuning (15 trials) | F1 improved to 0.606 with optimized parameters |
| Model Registry | `rain-classifier` v1 with `production` and `staging` aliases |
| Deployment | REST API on `http://127.0.0.1:5001` |
| Drift Monitoring | Detected 4.5% accuracy drop and 65% recall collapse |

---

## Key Insight from Monitoring

The drift simulation revealed an important real-world finding: while accuracy dropped only modestly (4.5%), recall collapsed by over 65%. This shows that **monitoring accuracy alone is dangerous** in production. Multiple complementary metrics must be tracked to catch silent model failures.
